# 개인정보처리방침 근거 문서

본 문서는 **Effortless Launcher**(이하 "본 앱")가 실제로 수집·처리·저장하는 데이터를 코드 레벨에서 조사한 결과를 정리한 것이다. 개인정보처리방침(Privacy Policy) 작성 시 사실관계의 근거 자료로 사용된다.

조사 시점: 2026-04-28
대상 버전: `pubspec.yaml` version 1.5.0+4

---

| 제3자 제공 | **없음** |

## 2. 수집·처리하는 정보 항목

### 2.1 설치된 앱 목록 (필수)

- **수집 항목**: 앱 표시 이름, 패키지명(packageName), 시스템 앱 여부, 앱 아이콘(비트맵)
- **수집 근거 권한**: `android.permission.QUERY_ALL_PACKAGES` ([AndroidManifest.xml:3-4](../android/app/src/main/AndroidManifest.xml#L3-L4))
- **수집 방법**: Flutter 패키지 [`installed_apps: ^2.1.1`](../pubspec.yaml#L37) 의 `InstalledApps.getInstalledApps()` 호출 ([lib/main.dart:471-474, 511-514](../lib/main.dart#L471-L514))
- **수집 목적**: 런처의 핵심 기능(앱 검색·실행·아이콘 표시)을 위해 단말기에 설치된 앱을 나열
- **외부 전송**: 없음

### 2.2 앱 실행 기록 (런처 내부 발생)

- **수집 항목**: 사용자가 본 앱을 통해 실행한 앱의 패키지명 + 실행 시각 타임스탬프(epoch ms)
- **저장 위치**: SharedPreferences 키 `launch_log_v1` ([lib/main.dart:19, 354-385](../lib/main.dart#L19-L385))
- **저장 형식**: `{ "패키지명": [최신 타임스탬프, ...최대 50개] }` JSON
- **보관 한도**: 패키지당 최근 50회 (`_kMaxLaunchesPerApp = 50`, [lib/main.dart:27](../lib/main.dart#L27))
- **사용 목적**: Hot Zone(자주 쓰는 앱)·검색 페이지 "Recently Used" 정렬
- **외부 전송**: 없음

### 2.3 Android 앱 사용 통계 — 최근 30일 (선택)

- **수집 항목**: 다른 앱들의 포그라운드 진입 이벤트(`MOVE_TO_FOREGROUND` / `ACTIVITY_RESUMED`)의 패키지명 + 타임스탬프
- **수집 근거 권한**: `android.permission.PACKAGE_USAGE_STATS` ([AndroidManifest.xml:5-6](../android/app/src/main/AndroidManifest.xml#L5-L6))
- **권한 부여 시점**: 사용자가 첫 실행 시 다이얼로그에서 "Set up" 선택 후 Android 시스템 설정에서 직접 허가 ([lib/main.dart:235-260](../lib/main.dart#L235-L260))
- **수집 방법**: Android 시스템의 `UsageStatsManager.queryEvents()` ([MainActivity.kt:174-211](../android/app/src/main/kotlin/com/onethelab/effortless_launcher/MainActivity.kt#L174-L211))
- **조회 범위**: 최근 30일, 패키지당 최대 50건 ([lib/main.dart:31, 269-272](../lib/main.dart#L269-L272))
- **수집 목적**: Hot Zone을 즉시 사용 가능하게 하기 위한 1회성 워밍업(warm-up). 워밍업 완료(`_warmupState = done`) 후에는 재조회되지 않음
- **저장 형식**: 위 2.2의 `launch_log_v1`에 병합되어 저장됨 (별도 보관 안 함)
- **사용자 거부 가능**: 다이얼로그에서 "Skip" 선택 가능. 거부 시 본 앱 내부 사용 기록만으로 점진적으로 학습됨
- **외부 전송**: 없음

### 2.4 알림 개수 (선택)

- **수집 항목**: 패키지별로 활성 알림의 **개수만** (지속 알림·포그라운드 서비스·그룹 요약 알림 제외, [EffortlessNotificationListener.kt:55-69](../android/app/src/main/kotlin/com/onethelab/effortless_launcher/EffortlessNotificationListener.kt#L55-L69))
- **수집하지 않는 항목**: **알림의 제목·본문·발신자·시각·확장 데이터 등 일체의 알림 내용물에는 접근하지 않음**
- **수집 근거 권한**: `android.permission.BIND_NOTIFICATION_LISTENER_SERVICE` ([AndroidManifest.xml:37-45](../android/app/src/main/AndroidManifest.xml#L37-L45))
- **권한 부여 시점**: 사용자가 다이얼로그에서 "Enable" 선택 후 Android 시스템 설정에서 직접 허가 ([lib/main.dart:310-352](../lib/main.dart#L310-L352))
- **저장 위치**: **메모리 휘발성** — 디스크에 저장되지 않음. `EffortlessNotificationListener` 의 `companion object counts` 맵에만 보관, 앱/리스너 종료 시 소실 ([EffortlessNotificationListener.kt:13, 42-45](../android/app/src/main/kotlin/com/onethelab/effortless_launcher/EffortlessNotificationListener.kt#L13-L45))
- **사용 목적**: 앱 아이콘 위 미확인 알림 배지 숫자 표시
- **사용자 거부 가능**: 다이얼로그에서 "Skip" 선택 가능. 거부 시 배지 미표시
- **외부 전송**: 없음

### 2.5 앱 설치 시점 추정값 (런처 내부 발생)

- **수집 항목**: 본 앱이 처음 인지한 시점(epoch ms)
- **저장 위치**: SharedPreferences 키 `installed_at_v1` ([lib/main.dart:23, 418-433](../lib/main.dart#L418-L433))
- **사용 목적**: 미사용 앱 페이지에서 "신규 설치 후 일정 기간이 지나도록 사용 안 한 앱"을 감지
- **외부 전송**: 없음

### 2.6 삭제된 앱 기록 (런처 내부 발생)

- **수집 항목**: 본 앱을 통해 삭제된 앱의 표시 이름, 패키지명, 삭제 확인 시각
- **저장 위치**: SharedPreferences 키 `deleted_apps_v1` ([lib/app_cache.dart:29, 94-114](../lib/app_cache.dart#L94-L114))
- **보관 한도**: **1년 후 자동 삭제** (`_kDeletedRecordTtlMs = 365일`, [lib/main.dart:26, 435-444](../lib/main.dart#L435-L444))
- **사용 목적**: "Deleted Apps" 페이지에서 재설치 안내 (Play Store 링크 제공)
- **외부 전송**: 없음

### 2.7 사용자 환경설정

| 키 | 내용 | 위치 |
|---|---|---|
| `protected_apps_v1` | 일괄 삭제 보호 대상 패키지 목록 | SharedPreferences |
| `last_page_index_v1` | 마지막으로 본 페이지 인덱스 | SharedPreferences |
| `warmup_state_v1` | Hot Zone 워밍업 진행 상태 | SharedPreferences |
| `notif_prompt_shown_v1` | 알림 권한 안내 다이얼로그 표시 여부 | SharedPreferences |

위 모든 항목은 본 앱의 동작 환경 기억 용도로만 사용되며 외부로 전송되지 않는다.

### 2.8 앱 아이콘 캐시

- **저장 위치**: `getApplicationSupportDirectory()/icon_cache/` 디렉터리 내 패키지별 `.bin` 파일 ([lib/app_cache.dart:32-45, 84-92](../lib/app_cache.dart#L32-L92))
- **내용**: 다른 앱들의 아이콘 비트맵
- **갱신 주기**: 설치 앱 변경 감지 시 갱신, 미설치 패키지의 아이콘은 자동 정리 ([lib/app_cache.dart:116-130](../lib/app_cache.dart#L116-L130))
- **외부 전송**: 없음

본 앱이 **요청하지도 사용하지도 않는** 권한 및 정보:

- 위치 정보(`ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION`)

조사 근거: [AndroidManifest.xml](../android/app/src/main/AndroidManifest.xml) 전체에서 위 권한 요청이 일체 없음.

## 4. 데이터 발송(전송) 처리 방침

### 4.1 외부 서버 전송 — 없음

- 본 앱의 release 빌드 [AndroidManifest.xml](../android/app/src/main/AndroidManifest.xml)에는 `android.permission.INTERNET` 권한이 **선언되어 있지 않다**. 따라서 OS 차원에서 모든 네트워크 통신이 차단된다.
- `INTERNET` 권한은 [debug/AndroidManifest.xml:6](../android/app/src/debug/AndroidManifest.xml#L6) 및 [profile/AndroidManifest.xml:6](../android/app/src/profile/AndroidManifest.xml#L6) 에만 존재한다. 이는 Flutter 개발 도구(hot reload, DevTools)와의 통신을 위한 것으로, **개발자 PC와의 로컬 통신 전용**이며 사용자에게 배포되는 release 빌드에는 포함되지 않는다.

### 4.2 외부 링크 열기 (앱 자체의 전송 아님)

- "Deleted Apps" 페이지에서 사용자가 항목을 탭하면 [Play Store URL](../lib/deleted_apps_page.dart#L36)을 Android Intent로 열도록 위임한다 (`url_launcher` 패키지). 이는 사용자 클릭에 의한 외부 앱(Play Store / 브라우저) 호출일 뿐, 본 앱이 데이터를 송신하는 행위가 아니다.
- 전송되는 데이터는 URL에 포함된 패키지명뿐이며, 이는 사용자가 명시적으로 선택한 항목에 한한다.

### 4.3 제3자 SDK — 없음

[`pubspec.yaml`](../pubspec.yaml) 의 의존성 전체:

| 패키지 | 용도 | 네트워크 통신 |
|---|---|---|
| `flutter` | 프레임워크 | 없음 |
| `cupertino_icons` | 아이콘 폰트 | 없음 |
| `installed_apps` | 설치 앱 조회 | 없음(로컬 PackageManager 호출) |
| `shared_preferences` | 로컬 키-값 저장 | 없음 |
| `path_provider` | 로컬 디렉터리 경로 | 없음 |
| `url_launcher` | 외부 URL Intent 호출 | 없음(OS에 위임) |

Firebase, Google Analytics, Crashlytics, Sentry, AppsFlyer, Adjust, Facebook SDK, AdMob 등 **분석·광고·추적 SDK 일체 미포함**.

## 5. 데이터 보관 처리 방침

### 5.1 저장 위치

모든 데이터는 사용자 단말의 본 앱 전용 샌드박스 영역에만 저장된다:

- **SharedPreferences**: Android의 표준 로컬 저장소. 다른 앱이 접근 불가.
- **Application Support 디렉터리**: `getApplicationSupportDirectory()` (앱 전용 영역).

### 5.2 보관 기간

| 데이터 | 보관 기간 |
|---|---|
| 앱 실행 기록 | 패키지당 최근 50건만 보관, 이후 오래된 항목부터 자동 삭제 |
| 사용 통계 워밍업 데이터 | 1회 가져와 실행 기록에 병합 후 별도 보관 안 함 |
| 알림 개수 | 메모리 휘발성, 즉시 소멸 |
| 삭제된 앱 기록 | 삭제 확인 후 **1년**, 이후 자동 삭제 |
| 앱 아이콘 캐시 | 설치 앱 변경 시 미설치분 자동 정리 |
| 환경설정 | 사용자가 변경하거나 앱 데이터 삭제 시까지 |

### 5.3 사용자에 의한 삭제

사용자는 Android 시스템 설정 → "앱 정보" → "저장공간" → **"데이터 삭제"** 또는 **앱 제거**를 통해 위 모든 로컬 데이터를 즉시 완전 삭제할 수 있다.

## 6. 결제 정보

[lib/donation_dialog.dart](../lib/donation_dialog.dart)의 후원(Donate) 다이얼로그는 현재 UI만 구현되어 있으며 "Donate" 버튼을 눌러도 "Coming soon" 스낵바만 표시된다 ([donation_dialog.dart:66-74](../lib/donation_dialog.dart#L66-L74)).

향후 인앱결제(IAP) 구현 시:
- Google Play Billing 라이브러리 사용 예정 ([CLAUDE.md](../CLAUDE.md))
- 결제 처리는 Google Play 서버가 담당하며, 본 앱은 신용카드/계좌 등 결제 수단 정보를 직접 수집·보관·전송하지 않는다.
- 본 문서는 IAP 구현 완료 시점에 갱신 필요.

## 7. 권한 요약표 (release 빌드 기준)

| 권한 | 필수/선택 | 사용처 | 사용자 동의 흐름 |
|---|---|---|---|
| `QUERY_ALL_PACKAGES` | 필수 | 설치 앱 목록 조회 | 설치 시 자동 부여 (런처 본질 기능) |
| `PACKAGE_USAGE_STATS` | 선택 | Hot Zone 워밍업(최근 30일 사용 기록 1회 조회) | 첫 실행 시 다이얼로그 → Android 설정에서 사용자가 직접 토글 |
| `BIND_NOTIFICATION_LISTENER_SERVICE` | 선택 | 알림 개수 배지 (개수만, 내용 미수집) | 다이얼로그 → Android 설정에서 사용자가 직접 토글 |

선택 권한은 거부 시에도 본 앱의 핵심 기능(앱 검색·실행·삭제)이 정상 동작한다.
