# Play Console 권한 정당화 문구

Play Console 앱 콘텐츠 → 권한 선언, 또는 향후 심사 거부/이의제기 대응용 영문/한글 정당화 문구 모음.

작성 시점: 2026-05-18
대상 버전: 1.6.0+16

---

## 1. QUERY_ALL_PACKAGES

런처 핵심 기능을 위해 필수. Play Console "권한 선언"에 명시적으로 요구됨 — 이미 제출 완료.

### English (≈395 chars)
```
Effortless Launcher is an Android home launcher (CATEGORY_HOME). It must enumerate every installed app to display, search, launch, and surface unused apps for cleanup. The app list is used only on-device; the app declares no INTERNET permission, so nothing is sent to any server or third party. QUERY_ALL_PACKAGES is the documented Android mechanism for launchers; no narrower alternative exists.
```

### 한국어
```
본 앱은 Android 홈 런처(CATEGORY_HOME)입니다. 런처 기능 수행을 위해
기기에 설치된 모든 앱을 열거하여 홈 화면 표시, 앱 검색, 실행 및
미사용 앱 정리에 사용합니다. 본 앱은 INTERNET 권한을 선언하지 않으며,
앱 목록은 단말기 외부로 전송되지 않습니다 (서버·제3자 송신 없음).
QUERY_ALL_PACKAGES는 모든 사용자 실행 가능한 앱을 나열하기 위한
Android 공식 메커니즘이며, 런처에는 더 좁은 대안 API가 없습니다.
```

## 2. PACKAGE_USAGE_STATS

특수 액세스(Special access) 카테고리 권한. Play Console 권한 선언 폼에는 표시되지 않으나, 수동 심사·이의제기 대응용으로 보관.

### English (≈540 chars)
```
Effortless Launcher optionally reads recent app-launch timestamps (last 30 days, one-time fetch) to pre-fill the "Hot Zone" of frequently used apps so the user is not stuck with an empty home screen on first launch. Disabled by default; the user must explicitly grant Usage Access in Android Settings. The data is used only on-device for ranking — the app has no INTERNET permission, so nothing is transmitted. Declining this permission does not affect any other feature; Hot Zone simply warms up over time as the user launches apps.
```

### 한국어
```
Effortless Launcher는 사용자 동의 하에 최근 30일간의 앱 실행 시각을
1회 조회하여 "Hot Zone"(자주 쓰는 앱) 초기 정렬에 사용합니다. 기본값은
비활성이며, 사용자가 Android 설정에서 "사용 정보 액세스"를 직접 허용해야
합니다. 조회한 데이터는 단말기 내부에서 정렬에만 사용되며, 본 앱은
INTERNET 권한이 없어 외부로 전송되지 않습니다. 사용자가 거부해도 다른
기능에는 영향 없으며, Hot Zone은 사용자가 앱을 실행할수록 자동으로
학습됩니다.
```

## 3. BIND_NOTIFICATION_LISTENER_SERVICE

특수 액세스 카테고리. Google이 알림 리스너 권한을 가장 까다롭게 보므로
정당화 문구를 가장 명확하게 작성. 수동 심사 시 코드 확인 가능성 있음.

### English (≈610 chars)
```
Effortless Launcher uses notification access strictly to count unread notifications per package and display a numeric badge on the corresponding app icon on the launcher's home screen and search grid. The app does not read, store, or process notification content — no titles, body text, sender, attachments, or actions are accessed. Counts live only in memory and are dropped when the app exits; nothing is persisted to disk. The feature is optional, disabled by default, and the user must explicitly grant Notification Access in Android Settings. The app declares no INTERNET permission, so no data is transmitted anywhere.
```

### 한국어
```
Effortless Launcher는 알림 접근 권한을 패키지별 미확인 알림 "개수"만
세어 런처 홈/검색 화면의 앱 아이콘 위 숫자 배지로 표시하는 용도로만
사용합니다. 알림의 제목, 본문, 발신자, 첨부, 작업 버튼 등 일체의 내용은
읽거나 저장·처리하지 않습니다. 개수는 메모리에만 보관되며 앱 종료 시
즉시 소멸하고, 디스크에 저장되지 않습니다. 본 기능은 선택이며 기본값
비활성, 사용자가 Android 설정에서 "알림 액세스"를 직접 허용해야 합니다.
본 앱은 INTERNET 권한이 없어 데이터가 외부로 전송되지 않습니다.
```

### 코드 근거 (수동 심사 대응)
- 알림 리스너 구현: [android/app/src/main/kotlin/.../EffortlessNotificationListener.kt](../android/app/src/main/kotlin/) — 패키지별 카운트만 증가, `Notification.extras`/`tickerText` 등 콘텐츠 필드 접근 없음
- 카운트 저장소: [lib/notification_counts.dart](../lib/notification_counts.dart) — 인메모리 `Map<String, int>` 만 사용, SharedPreferences·파일 저장 없음
